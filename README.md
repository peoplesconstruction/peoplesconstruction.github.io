# peoplesconstruction.github.io

### Basic Website Structure
1. Home – Big project photos + clear message like 
	“BCCA Peoples Construction LTD”, est. 2009
2. Services – List what you offer (landscaping, paving, lighting, decks, etc.).
3. Portfolio / Projects – Before & after photos to build trust.
4. About Us – Your experience, background, why clients should choose you.
5. Contact – Phone, WeChat, email, contact form. Free consultation

### Important Considerations
1. You should build a bilingual website (Chinese + English)
2. Large project photos (Before/after project photos)
3. Clear service categories
4. Mobile-friendly design
5. Strong local SEO (e.g., “Vancouver landscaping contractor”)
6. Clear repo organization to add photos to each website page. (i.e. generate placeholder .jpegs)
